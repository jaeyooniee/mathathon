# mathathon
Building Mathathon from scratch (2026/08/30)

The project will be progressed with the purposes below.
- To help students study and review University Mathematics modules with questions.
- To personally get exposed and practice the use of technicals in both front and back ends.


**Mathathon** is a platform which helps student from not forgetting what they have learned at university. 
I found the importance of keeping in mind of the mathematical concepts and their application and usage when I faced some of online assessments for summer internships. 
Even if you are not directly using the platform for your preparation to the internships, it will hopefully assist you not to forget basic concepts and their applications in general. 


## Plans
**v0.1**
- Updated on 30/08/2026
- The modules of the first version will be focused on Probability and Statistics, which will cover most part of what you learn in your first year and online assessments.
- Tech Stack
    - Frontend: Next.js + TypeScript
    - Backend: Python + FastAPI
    - API: REST API
    - DB: PostgreSQL
- MVPs
    - Login Service
    - Searching Questions
    - Choosing Topics/Difficulties
    - Providing answers
    - Saving logs
    - Dashboard/Bookmarks
